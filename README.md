# Modernization Mapper

A buildless application-portfolio decision tool. Add applications, map them against business value and technical health, and review a first-pass keep/evolve/replace/retire recommendation.

The included data is illustrative. Real modernization decisions should also account for dependencies, security, compliance, organizational readiness, and user research.

## Run locally

Open `index.html`, or serve the directory with any static HTTP server. Browser data is stored with `localStorage`.
